# grill-me

Project-local copy of the `grill-me` agent skill used to pressure-test plans and decisions before implementation.

Upstream: `satya-janghu/agent-skills/skills/grill-me`

Use it by asking to “grill me”, “pressure-test this”, or “help me think through” a plan. The skill asks one question at a time, recommends an answer to react to, drills into assumptions, and writes a distilled session log under `.grill/` when the discussion converges.
